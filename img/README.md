# 圖片資料夾

把圖片用下列「固定檔名」上傳到這個資料夾，網頁重新整理後就會自動貼到模型上（檔名大小寫要一致）。

| 檔名 | 位置 |
|---|---|
| `led_oh_n.jpg` | 歌劇院北側 2F 玻璃內的 LED 電視（1200 × 250 cm，建議 2400 × 500 px） |
| `sticker_se.png` | 東南角玻璃帷幕貼紙（L 型：南面轉角小片＋東面 3 片，506 × 340 cm） |
| `sticker_nw.png` | 西北角玻璃帷幕貼紙（L 型：北面轉角小片＋西面 3 片，540 × 348 cm） |
| `sticker_ne.png` | 東北角玻璃帷幕貼紙（L 型：東面 5 片＋北面轉角小片，818 × 348 cm） |
| `stage_oh.jpg` | 歌劇院鏡框式舞台 |
| `stage_ph.jpg` | 戲劇院鏡框式舞台 |
| `parking_B1.png` | B1 地下停車場平面圖（電梯按 B1 時彈出） |
| `parking_B2.png` | B2 地下停車場平面圖（電梯按 B2 時彈出） |

位置在 `config/screens.json`。

**玻璃貼紙**用透明背景的 PNG，比例照 `templates/` 裡的範本（每 cm 2 px，例如東北角 1636 × 696 px）。範本用紅色標出玻璃接縫（鋁框）和建議避開的範圍，箭頭、文字等重點請放在接縫之間。圖片由左到右對應「站在建築外面、面向轉角」看到的樣子。網址加 `?screens=test` 會直接用範本貼在模型上，方便對照接縫位置。
