# 教學檔案（教材）

每份教材一個資料夾，資料夾名稱＝教學代碼＝txt 檔名，用到的 svg、圖片放在同一個資料夾：

```
lessons/
  evac/
    evac.txt      ← 簡報內容
    evac.svg      ← 逃生動線圖層
    exit.jpg      ← 文字框裡的照片（選用）
```

開啟方式（兩種都可以）：
- 網址後面加 `?course=evac`，例如 `https://lmc10520.github.io/NKCA/?course=evac`，直接貼給學生；網址已經有 `?` 時用 `&course=evac`。
- 在網頁「設定 → 簡報」的輸入框打 `evac`。播放時網址列會自動變成帶 `?course=` 的連結，可以直接複製。

代碼（資料夾、檔名）只用英文小寫、數字、`-`、`_`。舊的 `lessons/代碼.txt`（不放資料夾）也能開。

## txt 寫法

- `NKCA1:…` 一行是一頁（在網頁按「記住目前畫面」複製）
- `# 標題`、`## 副標`、其他文字為內文
- `@svg 檔名.svg`：平面圖層（逃生動線、集合點…），貼在模型平面上、跟著建築對齊
  - 不是用預設範圍的底圖畫的，後面加範圍：`@svg 檔名.svg x0,y0,x1,y1`（下載底圖時網頁會告訴你、並複製好）
  - 選用：`z=300`（圖層高度 cm，預設 150）、`depth`（被建築擋住的部分不顯示；預設永遠顯示在最上層）
  - 一頁可以有多個 `@svg`
- `@img 檔名.jpg`：顯示在文字框裡的圖片
- `//` 開頭為註記，不顯示

## 畫 SVG 圖層（Illustrator）

1. 網頁「設定 → 簡報」按地圖圖示「下載平面底圖」，會下載俯視、北朝上的 PNG（檔名有範圍）。畫面拉遠看整個基地時是預設範圍；拉近則是目前看到的範圍。
2. Illustrator 開新檔，置入 PNG，「物件 → 工作區域 → 符合作品範圍」，讓畫板和底圖一樣大。
3. 在新圖層畫線條、箭頭（建議線寬 4–8 px，箭頭用筆畫或展開成路徑都可以）。
4. 「檔案 → 轉存 → 轉存為…→ SVG」，勾「使用工作區域」。底圖留著沒關係，網頁會自動忽略 SVG 裡的點陣圖。
5. 上傳到 GitHub 前可以先預覽：網頁「簡報」按投影片圖示，把 txt 和 svg 一起選取匯入。
