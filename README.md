# NKCA 3D 導覽

> 非官方模型，僅供教育訓練使用，與場館官方無關。

這是用 Three.js 做的靜態網頁，可以直接放在 GitHub Pages 上，不需要任何建置步驟。

## 檔案結構

```
index.html          網頁本體
css/style.css       介面樣式
js/                 程式（main.js 為入口）
model/nkca.glb      3D 模型（由 Fusion 360 匯出後壓縮）
config/*.json       所有可調整的內容：模式、燈光、電梯、標籤、LED 貼圖、資訊卡、車輛路線、噴泉
img/                LED 電視、舞台貼圖、地下停車場平面圖（見 img/README.md）
tools/              模型匯出與壓縮工具
```

## 更新模型（抽換檔案即可）

1. 在 Fusion 360 執行 `tools/fusion_export_glb.py`。它會把整個設計匯出成 `文件/NKCA_data/nkca.glb`，物件名稱維持 Fusion 裡的 body 名稱。
2. 用 `tools/build_model.sh 路徑/nkca.glb` 壓縮。約 240 MB 會壓到 9 MB 左右，壓縮後的檔案輸出到 `model/nkca.glb`。
3. 產生預設使用的減面模型：`node tools/build_lite.mjs`（讀 `model/nkca.glb`，輸出 `model/nkca_lite.glb`，約 2 秒）。
4. 上傳覆蓋 `model/nkca.glb` 和 `model/nkca_lite.glb`。

減面只針對面數多、但看起來平或很小的物件（廣場地坪 32 萬面 → 1 萬、噴泉 LED、售票亭坡道、天花、電梯井…），外框邊界鎖住不動，欄杆不減。規則寫在 `tools/build_lite.mjs` 最上面。總面數約 150 萬 → 59 萬，檔案 8.8 MB → 5 MB。

網頁功能都靠「物件名稱」對應：模式隱藏、燈光、廳院樓層、資訊卡都是。所以 Fusion 裡的 body 名稱保持一致，換模型後所有功能照常運作。

## 操作

| 動作 | 電腦 | 手機／平板 |
|---|---|---|
| 平移 | 左鍵或中鍵拖曳 | 單指拖曳 |
| 旋轉、傾斜 | 右鍵拖曳，或 Ctrl＋左鍵 | 雙指旋轉 |
| 縮放 | 滾輪 | 雙指捏合 |
| 取座標 | Shift＋點擊（座標會複製到剪貼簿，單位 cm、Fusion 座標） | — |

- **模式按鈕**（右側）：外觀／樹冠大廳／榕樹廣場。隱藏清單來自 Fusion 的選取集 `MODE_A_CanopyHall_hide`、`MODE_B_BanyanPlaza_hide`。
- **交通核電梯**：把畫面中心移到交通核附近並拉近鏡頭，右側就會出現樓層按鈕。按 3F 切到樹冠大廳模式，按 1F／2F 切到榕樹廣場模式，按 B1／B2 會彈出地下停車場平面圖。
- **廳院樓層**：在榕樹廣場模式中靠近表演廳、戲劇院，右側會出現該廳的樓層按鈕。上層會以「升起」動畫顯示。
- **左上**：指北針只指真北（模型 +Y 軸順時針 23°，`site.json` 的 `northOffset_deg`），點一下轉成北朝上。下方的視角方塊依建築 X-Y-Z 軸（紅 X、綠 Y、藍 Z）：點面＝俯視或該面立面，點上方四個角＝等角視角，左上的小房子＝回到起始視角。
- **標籤與資料卡**：標籤放在該位置最上層表面上方，被建築擋住時自動隱藏。有資料卡的標籤帶小箭頭，點一下往下展開。內容寫在 `labels.json` 的 `card`。
- **室內標示**（`pois.json`）：建築物裡面（四個廳院樓面、3F 樹冠大廳）的小圖示或地點文字，立在樓面上，只在指定模式／廳院樓層出現。圖示在 `img/icons/`。新增方法：在網頁按住 Shift 點樓面，會複製一行設定，填上 `icon`（或 `text`）後貼進 `items`。
- **設定（左下）**：顯示開關（標籤、時間、天氣、人車、場館燈光）、指定時間、天氣預覽（即時／晴／陰／雨／雪）、模型樣式（彩色／彩色＋線／白模／線稿／線稿＋網點，線條粗細、網點大小）、投影（透視／等角平行）、畫質（預設／高畫質）、簡報。
- **場館燈光**（設定 → 顯示，人車下方）：預設依 `lights.json` 的營運時間自動開關（23:00 熄燈）。關燈時間有迎賓需求時把開關打開；手動切換後會出現「自動」，按一下回到排程。路燈、車燈不受影響。
- **迎賓模式**：設定最上方長按鈕＝時間天氣大字置中＋模型自轉；旁邊的小按鈕（3D 旋轉圖示）＝純轉動，只有轉動的模型，不顯示時間、日期、天氣和提示文字。兩種都是點一下或拖曳畫面就結束。
- **概覽**（右上）：計程車招呼站、周邊道路及建物、捷運站出入口、哺乳室、飲水機。點分類會依序帶到每個定點（上一個／下一個），同一類的圖示框上分類顏色。分類在 `config/overview.json`；定點用 `pois.json` 的圖示加上 `"cat": "water"` 這類分類 id，或在分類的 `items` 直接寫；捷運出入口、周邊道路可以填 `course`（教學代碼），直接開 `@svg` 標好顏色、編號、方向的教材。
- **節慶物件**（`config/festivals.json`）：萬聖節南瓜氣球＋建築鬼怪投影、聖誕樹（另有通用的大型充氣球 ball 類型可用）。檔期到了自動出現（台灣時間），設定 →「節慶物件」可以關閉；教材簡報預設不顯示。網址加 `?festival=xmas`（或 `?festival=halloween,xmas`）可不管檔期直接預覽。
- **天氣預覽**：即時／晴／陰／雨／雪／颱風（斜飄大雨＋閃電）／極光（夜間北方天空；白天選擇會自動切到 21:00）。即時天氣遇到雷雨也會有閃電。
- **標籤圓點**：各廳院識別色（CH #DABE00、RH #E98B19、OH #E50012、PH #0072BE，其他公共空間與交通核 #2B8D56），在 `labels.json` 的 `venue`／`colors`。
- **LED 與玻璃貼紙**：`config/screens.json`。歌劇院北側 LED 1200 × 250 cm；東南、西北、東北角 L 型玻璃貼紙。範本（標出玻璃接縫）在 `img/templates/`，網址加 `?screens=test` 用範本檢查位置，詳見 `img/README.md`。
- **公共鋼琴**（榕樹廣場、表演廳旁）：滑鼠移到鋼琴上，游標變成手形、鋼琴外框發亮，旁邊跳出「點擊公共鋼琴，看看誰來彈鋼琴！」；手機沒有 hover，鏡頭靠近時鋼琴上方會常駐小提示（點提示也可以）。被屋頂擋住時不會誤觸。曲子放在 `audio/piano/`。
- **建築聲景**（右下喇叭按鈕）：不同空間播放不同的環境音（外觀／鳥瞰／戶外劇場／草坪／榕泉／榕樹廣場與各廳前廳／樹冠大廳，下雨時疊加雨聲），切換空間時交叉淡入淡出、循環不斷音；鋼琴彈奏時環境音自動淡出靜音，停止後恢復。按鈕是全域聲音開關（也包含鋼琴），會記住選擇；設定 → 建築聲景可調音量並看目前播放的區域。音檔放法見 `audio/soundscape/README.md`。
- **簡報模式**：
  1. 調好視角、模式和各個開關後，在設定中按「記住目前畫面 → 複製代碼」，會複製一行 `NKCA1:...` 代碼。
  2. 把代碼依序貼到記事本存成 .txt，每個代碼是一頁。代碼下方可以寫文字（範例：`lessons/demo/demo.txt`）：
     - `# 標題` → 大標題（H1）
     - `## 副標` → 副標題（H2）
     - 其他文字 → 內文，可多行
     - `@svg 檔名.svg` → 平面圖層（逃生動線等），貼在模型平面上、轉動視角也對齊建築
     - `@screen 檔名.svg` → 畫面圖層，疊在這一頁的畫面上（任意視角），拖曳畫面時淡出
     - `@img 檔名.jpg` → 文字框裡的圖片
     - `//` 開頭 → 註記，不顯示
  3. 播放方式：
     - 教材放在 `lessons/代碼/代碼.txt`（圖片、svg 放同一個資料夾），網址後面加 `?course=代碼` 直接開啟，例如 `…/NKCA/?course=evac`，可以直接貼給學生；或在設定的輸入框打代碼。
     - 在設定中按簡報圖示匯入 txt（可以連同 svg、圖片一起選取，上傳前先預覽）。
     - 用 `|←`、`→|`（或方向鍵）切換，`✕` 或 Esc 結束。
  4. 畫平面圖層：設定 → 簡報 → 地圖圖示「下載平面底圖」，得到俯視、北朝上的 PNG（拉遠＝整個基地的預設範圍，拉近＝目前畫面範圍，範圍寫在檔名）。在 Illustrator 以底圖為畫板描線、轉存 SVG（使用工作區域）。任意視角則用旁邊的「下載目前畫面底圖」，配 `@screen`。詳見 `lessons/README.md`，範例：`lessons/evac/`。

## 模型樣式

| 樣式 | 用途 |
|---|---|
| 彩色 | 真實時間、天氣、晝夜光線 |
| 彩色＋線 | 彩色加上半透明輪廓線，建築量體比較清楚 |
| 白模 | 白色量體＋淡輪廓線＋陰影 |
| 線稿 | 只有看得到的邊線（印刷、描圖用） |
| 線稿＋網點 | 線稿加漫畫網點：亮面留白、背光面與陰影變成網點（設定裡可調網點大小） |

白模、線稿、網點使用固定的「攝影棚光」（`site.json` 的 `studioLight`），不受時間天氣影響，教材截圖每次都一樣。簡報代碼會記住樣式與網點大小。

色彩：色調映射用 Khronos PBR Neutral（保留材質原色，不像原本的 ACES 偏灰），加上環境反射（玻璃會反光）。草地、植栽、柏油的顏色在 `site.json` 的 `materialColor` 調整。

## 地平線、屋頂、星空

- **地平線**：基地外面延伸一片大地坪（`js/horizon.js`），從基地邊緣的淺色漸變到地平線，再加一圈霧帶把地面和天空分開，看不到四方形的基地邊緣。夜晚地坪在遠處漸漸變透明，鳥瞰時四周是星空。顏色、漸變距離在 `site.json` 的 `horizon`，`"enabled": false` 可關閉。
- **屋頂**：屋面顏色 `materialColor.Roof_White_Aluminum`（略降白度），直立縫另外用較深的 `seamColor`，凹凸線條比較清楚。
- **星空**：跟著鏡頭的天球，從天頂延伸到地平線以下約 30°，靠近地平線的星星較多。

## 畫質（預設／高畫質）

所有裝置一開始都是「預設」。效能好的電腦可以在 設定 → 畫質 切到「高畫質」（會記住），或網址加 `?q=high`；`?q=default` 回到預設。

| | 預設（所有裝置） | 高畫質（效能好的電腦） |
|---|---|---|
| 模型 | 減面模型 59 萬面（`nkca_lite.glb`） | 原模型 150 萬面 |
| 陰影 | 無 | 有 |
| 深度緩衝 | 一般深度＋依鏡頭距離調整 near（屋頂、玻璃邊緣不顫動） | 對數深度 |
| 夜間 | 光暈（bloom）、屋頂投射燈、廣場面光源、閃爍星空 | 同左 |
| 解析度 | 依幀率自動調整（手機像素比 0.8～1.5、電腦 1～2） | 同左 |

共通：平常直接繪製到畫面（只有夜間光暈、網點時才走後製），建築物件不再每幀重算矩陣；手機平板的人車模擬隔幀計算。
星空：2,200 顆星，亮度、大小、色溫各不相同，各自閃爍（靠近地平線閃得較明顯），少數亮星有十字星芒；固定星圖，每次載入都一樣。

## 設定檔速查

| 檔案 | 內容 |
|---|---|
| `site.json` | 模型路徑（含預設使用的減面模型 `modelLite`）、經緯度、起始視角、陰影／光暈、環境反射 `envIntensity`、天空亮度、色盤 `materialColor`、白模／網點的固定光源 `studioLight`、簡報平面圖層的預設範圍（`planFrame_cm`） |
| `modes.json` | 三種模式各自要隱藏的物件 |
| `lights.json` | 夜間燈光：玻璃暖光、天窗、露臺輪廓、戶外劇場燈條、廣場天花崁燈與頂光、屋頂投射燈 |
| `lawns.json` | 北側、東側圓形草坪的光環（從模型自動擷取） |
| `cores.json` | 交通核的位置與樓層按鈕 |
| `halls.json` | 廳院內局部樓層 |
| `screens.json` | LED 電視、舞台貼圖的位置與圖片檔名 |
| `labels.json` | 地點標籤與點開後的資料卡 |
| `pois.json` | 室內小圖示與室內地點文字 |
| `walk.json` | 行人可走的網格、人數與組成（成人／小孩／長者／輪椅／保全與狗） |
| `roads.json` | 車輛路線（夜間開車燈） |
| `piano.json` | 公共鋼琴的位置、朝向、曲目資料夾、手機提示距離（`hint_m`） |
| `soundscape.json` | 建築聲景：各空間的範圍、對應資料夾、音量、觸發條件、鋼琴避讓 |
| `festivals.json` | 節慶物件與檔期 |
| `overview.json` | 右側「概覽」的分類 |
| `fountain.json` | 旱地噴泉噴頭位置與營業時間（11:00–21:00 每小時整點，15 分鐘） |
