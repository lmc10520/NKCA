# 建築聲景（Soundscape Architecture）音檔

網頁會依照「目前的模式（外觀／樹冠大廳／榕樹廣場）＋畫面中心的位置＋鏡頭距離＋晝夜＋天氣」決定要播哪個空間的聲音。
每個子資料夾對應一個空間；把 mp3 放進去就會自動播放（GitHub Pages 上會自動讀取資料夾內容）。

| 資料夾 | 空間 | 類型 | 什麼時候播 |
|---|---|---|---|
| `overview/` | 鳥瞰・城市遠景 | 底景 | 外觀模式、鏡頭拉遠（與畫面中心距離超過 300 m，例如開場的鳥瞰視角） |
| `exterior/` | 建築外圍 | 底景 | 外觀模式的預設底景：建築外圍、周邊步道與道路旁（沒有落在其他區域時都播這裡） |
| `outdoor_theater/` | 戶外劇場 | 底景 | 外觀模式、畫面中心在戶外劇場附近（半徑約 45 m，中心 [11500, 8700] cm） |
| `north_lawn/` | 北側草坪 | 底景 | 外觀模式、畫面中心在北側草坪（矩形 x −1000～24000、y 23000～38000 cm） |
| `east_lawn/` | 東側草坪 | 底景 | 外觀模式、畫面中心在東側草坪（矩形 x 24000～32000、y 4500～30000 cm，靠三多一路／國泰路側） |
| `fountain/` | 榕泉水聲 | 疊加 | 疊加層：外觀模式、靠近榕泉（中心 [17150, 26146] cm，12 m 內全音量，往外到 45 m 漸弱） |
| `plaza/` | 榕樹廣場 | 底景 | 榕樹廣場模式的預設底景（1F 半戶外的大屋頂下空間） |
| `plaza_opera/` | 歌劇院前廳 | 底景 | 榕樹廣場模式、畫面中心在歌劇院入口前（半徑約 28 m） |
| `plaza_concert/` | 音樂廳前廳 | 底景 | 榕樹廣場模式、畫面中心在音樂廳入口前（半徑約 28 m） |
| `plaza_recital/` | 表演廳前廳 | 底景 | 榕樹廣場模式、畫面中心在表演廳周邊（半徑約 32 m；公共鋼琴也在這一區） |
| `plaza_playhouse/` | 戲劇院前廳 | 底景 | 榕樹廣場模式、畫面中心在戲劇院周邊（半徑約 35 m） |
| `canopy/` | 樹冠大廳 | 底景 | 樹冠大廳模式（3F 室內大廳） |
| `weather_rain/` | 雨聲 | 疊加 | 疊加層：下雨時（即時天氣，或設定 → 天氣預覽選「雨」），任何模式都會疊上去 |
| `weather_storm/` | 颱風・雷雨 | 疊加 | 疊加層：颱風／雷雨時（天氣預覽選「颱風」，或即時雷雨），會和雨聲一起疊加 |

- **底景**：同一時間只播一個，依 `priority` 選最符合的區域；移動到別的空間時交叉淡入淡出，約 2.5 秒。新空間的音檔下載解碼完成、開始播放後，舊的才淡出，所以不會出現空白。
- **疊加層**：疊在底景上，例如靠近榕泉時多了水聲、下雨時多了雨聲（室內會自動變小、變悶）。
- 某個資料夾還沒有音檔時會被略過：例如 `plaza_recital/` 是空的，表演廳周邊就繼續播 `plaza/` 的聲音。
- 公共鋼琴彈奏時，環境音會淡出到完全靜音（`duck` 的 `level: 0`），鋼琴停止或暫停後約 2.5 秒淡入回來。想保留一點環境音，把 `level` 改成 0.2 之類的數值即可。
- 右下角的喇叭按鈕＝全域聲音開關（也會讓鋼琴靜音），網頁會記住選擇；設定 → 建築聲景 可以調音量，並顯示「目前」正在播哪個區域。
- 瀏覽器規定要有使用者操作才能出聲：第一次點擊或觸控畫面後才開始播放（右下角會有小提示）。
- 要新增空間：在 `config/soundscape.json` 的 `zones` 加一筆（`id`、`name`、`trigger`…），再建立同名資料夾。

## 檔名規則

- 放 **mp3**（也可以用 m4a、wav；Safari 不支援 ogg）。檔名可以用中文，空白會自動處理。
- 資料夾裡的所有音檔會**隨機輪流**播放，每段結尾和下一段交叉淡入淡出（約 3 秒），所以沒有斷點，也**不需要剪成完美循環**。只有一個檔案時就是自己接自己循環。
- 檔名開頭加 `day_` → 只在白天播；加 `night_` → 只在夜晚播（依網頁上的時間，可在 設定 → 指定時間 預覽）。沒有前綴＝白天夜晚都播。
  例：`day_鳥叫與人聲.mp3`、`night_蟲鳴.mp3`、`風聲.mp3`
- 檔名開頭加 `_` → 草稿，不會播放（例如 `_未剪輯.mp3`）。
- 建議長度 1～3 分鐘、128 kbps、單聲道或立體聲皆可；檔案太長會佔用較多記憶體（手機上尤其明顯）。
- 開頭結尾不必淡入淡出，網頁會自己處理；但請避免開頭或結尾有突兀的聲音（關門、咳嗽）。
- 資料夾沒有音檔時網頁會自動略過，改播其他符合的區域，不會出錯。
- 只用有授權的錄音（自己現場錄最好）。
